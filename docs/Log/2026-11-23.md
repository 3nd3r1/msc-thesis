## The method

A semantic filter with a recall target that returns only rows the oracle confirmed.
The order is CAL, a logistic regression on the proxy logit, the embedding and counts of confirmed positive and negative neighbours, refit as verdicts come in.
QBCB stops it and gives the guarantee.

## BARGAIN as the baseline

BARGAIN plus checking every returned row is a fair baseline for this query.
It is what a user needing confirmed rows would do with BARGAIN, its recall query already minimises the returned set and so the checking, the guarantee is unchanged and its budget is picked in hindsight.
Plain CAL already beats it, so the BARGAIN column shows the approach is competitive and CAL against CAL with links is what shows the links help.

## links.py does not settle the unchecked query

Its cost column is the checked cost and its budget grid stops at 10% of the rows, the same flaw as 06.
So it says one two phase design lost on checked cost at small budgets, not that links can not help an unchecked set.
