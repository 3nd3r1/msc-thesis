## SYNERGY is a different setup

Each review is one predicate, its eligibility criteria, over a pool its own search returned.
Labels are final inclusion after full text, so some positives can't be told from the abstract.
SYNERGY marks 19 of the 46 files inactive, including all of Cohen_2006, which has no criteria to prompt a proxy with.

## Embeddings run on DeepInfra

Local MiniLM did about 10 texts a second, so Walker would have taken an hour.
DeepInfra serves the same model with identical vectors, so `embed.py` uses it when the key is set and the cache stays valid.
