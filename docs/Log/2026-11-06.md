# 2026-11-06

## The SYNERGY proxy gets the plain LOTUS prompt

On Cora and Stack the proxy got the strict prompt so it matched the oracle it stands in for.
SYNERGY has human labels, so there is no oracle prompt to match.
Eligibility criteria have several parts that an abstract rarely states in full, so the strict prompt would likely push most p(yes) to 0, and step 4 only uses the proxy's ranking.
A weak proxy would also leave easy positives for links to pick up, which makes proxy+links look better than it is.
`proxy` in `experiments/03_link_guided_search/run.py` now uses plain LOTUS on human-labelled datasets and the strict prompt everywhere else.
