## The SYNERGY proxy run decides RQ2

On Cora and Stack the oracle was the 70B with the same prompt as the 8B proxy, so the proxy was copying a bigger Llama (Oct 21).
SYNERGY's labels are human, so the proxy loses that head start and every order is scored against the same labels.
That makes it the fairest place to compare the proxy with links.
If proxy+links loses there too, RQ2 is negative on every dataset I have.
On SYNERGY the oracle is the screener, so the calls saved are screener calls, and the thesis has to say so where RQ2 says LLM calls.
I'm running proxy and cascade on my laptop, since the cloud container has neither the data nor the keys.
