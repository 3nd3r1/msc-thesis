## Link-guided idea

Thought about the paper idea: find all papers about semantic operators.
A person would start from one paper and follow citations.

Read [@pasa] about finding specific papers by expanding citations, with an LLM judging relevance.
Same mechanism, but it is an agent on the open web with no fixed table and no recall guarantee.
Active search on graphs and systematic review screening do similar things with a human as the oracle.
Didn't find anyone doing it inside a semantic filter.

The sem_filter from [@lotus] with a recall target is a good comparison.
It scores every row with a small LLM first.
CSV and Two-Phase only take an accuracy target, which a rare predicate meets by answering no to everything.
