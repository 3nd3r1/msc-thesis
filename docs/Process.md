# Process

Helsinki MSc thesis process, programme code MH50_009.

1. **Thesis plan** — 1–2 pages, submitted by the supervisor through PreThesis.
2. **Supervision agreement.**
3. **Seminar presentation** — no course enrolment needed; book a slot via the e-form on the seminar page at least two weeks ahead.
4. **Submission** — via Sisu / E-thesis. Graded 0–5 by two examiners.

The thesis is written in LaTeX on Overleaf. Figures and tables are generated in this repo and uploaded there.
