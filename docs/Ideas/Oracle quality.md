Cascades calibrate against the oracle's verdicts and nobody checks the verdicts.

In experiment 01 one prompt change flipped the labels on all 7 predicates, so this is worth a
look.

What to measure:

- oracle accuracy against a hand labelled set
- how much verdicts move across a few reasonable prompts
- what a wrong oracle does to the accuracy target a cascade claims
